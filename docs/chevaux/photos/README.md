# Photos des chevaux

Placez ici les fichiers photographiques au format JPG, sous le nom exact de l'identifiant du cheval : `lord-on-way.jpg`, `memphis-belle.jpg`, etc.

Les fiches et le catalogue affichent automatiquement chaque photo dès qu'elle est présente. Aucun code à modifier.

En attendant la photo, la casaque de l'Écurie Initial apparaît.
