Cliquez ensuite sur la notification reçue : la fiche d'ANDRESY doit s'ouvrir. Revenez sur cette page pour vérifier le résultat du clic.

Si ce test local fonctionne mais que les notifications automatiques n’arrivent pas, vérifiez « Dernier Push reçu » ci-dessus. Si le test local échoue, vérifiez les autorisations Android/iPhone et les notifications de l’application.

Après un envoi automatique

Après le test serveur depuis « Notifications », rouvrez cette page. Les lignes « Dernier Push reçu du serveur » et « Dernier Push affiché » permettent de savoir si le Push est arrivé au navigateur puis a été affiché. Le test local ne compte pas comme une réception du serveur.

Pour la confidentialité, seul l’état du diagnostic est conservé sur cet appareil ; ni le jeton ni l’adresse complète d’abonnement ne sont affichés.
