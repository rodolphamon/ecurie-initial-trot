Confidentialité

Les médias sont stockés dans un espace privé Supabase. Une notification n'inclut ni le texte privé ni le fichier ; elle invite le propriétaire à consulter son espace sécurisé.

L'envoi Push nécessite que le service de notifications soit activé dans Supabase. Publier ici ne garantit pas la réception d'une alerte tant que ce service n'est pas opérationnel.
