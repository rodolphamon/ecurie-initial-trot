Confidentialité

Les messages aux associés restent privés. Les annonces « Toute la communauté » sont publiques : texte et titre visibles par tous, même sans connexion.

Une notification n’est envoyée qu’aux appareils ayant activé les alertes correspondantes. Les alertes privées restent limitées aux associés autorisés.
