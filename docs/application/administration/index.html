📒 Répertoire des associés

Retrouvez ici les personnes de votre liste initiale, même si elles n'ont pas encore créé leur compte. Aucun e-mail n'est envoyé depuis cette liste.

Chargement du répertoire…

Cliquez sur « Préparer l'invitation » pour retrouver automatiquement ses chevaux dans le formulaire ci-dessous. Vous n'aurez plus qu'à saisir son e-mail et vérifier les chevaux avant l'envoi. Les personnes ayant déjà un compte utilisent « Lien d'accès » dans le tableau ci-dessus.

Invitations et gestion des accès

Préouverture jusqu’au 1er décembre 2026. Les personnes invitées peuvent créer leur mot de passe dès maintenant. Jusqu’au lancement officiel, l’accès aux espaces réservés reste limité aux personnes individuellement autorisées et aux testeurs habilités.

Les invitations sont individuelles et les droits d’accès restent contrôlés côté Supabase.

Pour une personne déjà connue, utilisez « Préparer l’invitation » dans le répertoire ci-dessus : ses chevaux seront cochés automatiquement.

🐎 Chevaux de cet associé

Cochez ses chevaux pour les rattacher dès la création du compte. Vous pourrez modifier cette liste ensuite.

Chargement des chevaux…

Les invitations sont individuelles. Aucun mot de passe ne doit être communiqué.

Pour corriger une adresse existante ou rattacher un cheval, choisissez le compte dans le tableau « Gestion des associés ».
