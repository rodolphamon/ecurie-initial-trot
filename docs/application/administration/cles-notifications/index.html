🔔 Installer les clés de notifications

Ces clés sont générées uniquement dans ce navigateur. Rien n'est transmis à Écurie Initial, Supabase ou GitHub par cette page. Les valeurs ne sont pas enregistrées localement.

Ouvrez cet outil sur votre ordinateur, puis copiez chacune des trois valeurs dans Supabase → Edge Functions → Secrets. Ne partagez jamais les valeurs privées par e-mail ou messagerie.

Important : Enregistrez les trois valeurs de la même génération. Ne cliquez pas une seconde fois sur « Générer » après avoir copié une première valeur.

Quand les trois secrets sont enregistrés, vous pouvez fermer cette page. Une nouvelle génération remplacerait les valeurs de cette page, et pourrait rendre les anciens abonnements Push incompatibles.
