Installation sur votre téléphone

📲 Installer l'application Écurie Initial

Retrouvez l'Écurie directement sur l'écran d'accueil de votre téléphone, comme vos autres applications.

✅ Installation gratuiteQuelques gestes suffisent. Vous pouvez installer l'application maintenant, même si vous n'avez pas encore activé votre compte.

✅ L'application est déjà ouverte comme une application installée. Vous n'avez rien à faire.

🤖 J'ai un téléphone Android

  1. Ouvrez cette page dans Chrome.
  2. Appuyez sur les trois points ⋮ du menu Chrome.
  3. Choisissez « Ajouter à l'écran d'accueil » ou « Installer l'application », puis confirmez.

Vous retrouverez l'icône Écurie Initial sur votre téléphone.

🍎 J'ai un iPhone

  1. Ouvrez cette page dans Safari.
  2. Appuyez sur Partager (le carré avec une flèche vers le haut ↑).
  3. Choisissez « Sur l'écran d'accueil » ou « Ajouter à l'écran d'accueil », puis appuyez sur « Ajouter ».

L'icône Écurie Initial apparaîtra sur votre écran.

Si vous avez ouvert le lien dans WhatsApp ou dans un e-mail, utilisez « Ouvrir dans Chrome » (Android) ou « Ouvrir dans Safari » (iPhone) avant de suivre ces étapes.
